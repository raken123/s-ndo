      Arduino link

      InfoDoc talks to an Arduino over a plain line protocol. Either transport works — they carry exactly the same messages.

      USB serial

      For a board whose sketch Serial is the USB port (UNO R4, Nano ESP32, MKR…), or an UNO Q exposing a USB CDC gadget.

      This build has no Web Serial API. Use the desktop app, or the network transport below.

      Network (UNO Q bridge)

      For an UNO Q running the uno_q_bridge app: the sketch reads the Modulinos on the MCU, Python relays them over a WebSocket.

      Read this before using it on a patient
      
    
        
      
      • InfoDoc is not a medical device and none of it is certified. The three checks are
      rough screening aids for a clinician who is already in the room — they do not diagnose
      anything and must not be used instead of proper equipment.
        • 
      
      • The Modulino Thermo is a contact temperature and humidity sensor, not an infrared
      thermometer. It reads skin temperature after a slow contact settle, which sits well
      below core temperature and is affected by sweat, draughts and how hard the node is pressed.
        • 
      
      • Records are held in plain text on this computer. Anyone with the machine can read them.
      Use full-disk encryption and a locked account, keep backups, and follow whatever your
      jurisdiction requires for patient data.
