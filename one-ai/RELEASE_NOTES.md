One AI 1.0.0: chatta och skapa vad som helst med One-modellerna och elva agenter.

| Plattform | Fil |
|---|---|
| Windows 10/11 | `OneAI-Setup-1.0.0.exe` |
| macOS Apple Silicon / Intel | `OneAI-1.0.0-mac-arm64.dmg` / `OneAI-1.0.0-mac-x64.dmg` |
| Debian / Ubuntu | `one-ai_1.0.0_amd64.deb` |
| Android 8+ | `OneAI-1.0.0.apk` (installera direkt), `OneAI-1.0.0.aab` (Google Play) |
| iPhone / iPad | `OneAI-1.0.0.ipa` (osignerad: signera med Sideloadly, AltStore eller Xcode) |
| Webbläsare | `OneAI-1.0.0.html` |

Apparna behöver adressen till en One AI Cloud-server (Inställningar → Allmänt),
om inte repo-variabeln `ONEAI_CLOUD_URL` var satt när de byggdes.
Betalningarna är en demo: inga pengar dras.

Installationshjälp och allt om planer, modeller, agenter och MCP:
[one-ai/README.md](https://github.com/raken123/s-ndo/blob/main/one-ai/README.md).
`SHA256SUMS.txt` har kontrollsummor för alla filer.
