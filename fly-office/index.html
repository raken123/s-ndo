    This is a toy model inspired by the FlyWire whole-brain connectome of Drosophila melanogaster: 139,255 neurons, mapped by the Princeton-led FlyWire consortium using Google's automated segmentation. The page runs a few hundred stand-in neurons arranged by real brain region. It does not use the real wiring. Learning follows the fly's actual reinforcement circuit: PPL1 dopamine neurons weaken Kenyon-cell synapses onto mushroom-body output neurons after punishment, and PAM neurons do the same for reward.
