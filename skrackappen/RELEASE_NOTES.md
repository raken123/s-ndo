**Skräckappen** – ett skräckspel om Kasper, Ruben, Tilda och appen som inte går att avinstallera. Fritt efter en idé ur en bok av Ann Olerot.

Prolog, åtta kapitel och en epilog · sex banor · sex minispel · tre slut · helt offline.

### Vilken fil ska jag ta?

| Fil | Till |
|---|---|
| `Skrackappen-Setup-1.0.0.exe` | **Windows** – installerar spelet (rekommenderas) |
| `Skrackappen-1.0.0-portable.exe` | Windows – startar direkt utan installation |
| `Skrackappen-1.0.0-mac-arm64.dmg` | **Mac** med Apple-chip (M1–M4) |
| `Skrackappen-1.0.0-mac-x64.dmg` | Mac med Intel-processor |
| `Skrackappen-1.0.0.apk` | **Android** 7.0 eller nyare |
| `skrackappen_1.0.0_amd64.deb` | Linux (Debian/Ubuntu) |

### Installera

- **Windows:** Om SmartScreen säger "Windows skyddade datorn", klicka **Mer information → Kör ändå**. Spelet är inte signerat med ett certifikat.
- **Mac:** Öppna DMG-filen och dra Skräckappen till Program. Första gången: **Systeminställningar → Integritet och säkerhet → Öppna ändå**.
- **Android:** Öppna APK-filen på mobilen och tillåt installation från den källan när Android frågar.
