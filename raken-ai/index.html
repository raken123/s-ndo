Get it

PlatformInstall
WebOpen the app — add it to your home screen or install it from the browser menu; it works offline.
WindowsDownload raken-ai-1.0.0-win32-x64.tar.xz (92.7 MB), extract, run RakenAI.exe.
macOSDownload raken-ai-1.0.0-macos-arm64.tar.xz (79.7 MB, Apple Silicon; Intel builds come from the workflow), extract, run xattr -dr com.apple.quarantine "Raken AI.app", open.
LinuxDownload raken-ai_1.0.0_amd64.deb (82.9 MB), then sudo apt install ./raken-ai_1.0.0_amd64.deb and run raken-ai.
AndroidDownload raken-ai-…-android.apk and install it (allow installs from this source).

Builds are attached to every GitHub release and to the Raken AI builds workflow runs.
