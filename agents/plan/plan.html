ChatGPT Agents — Build Plan

A ChatGPT-style chat app where you talk to agents, not just a single assistant.

1ChatGPT-style interface

  • Dark sidebar: New chat, search, chat history
  • Centered “What can I help with?” start screen
  • Rounded composer with model picker up top
  • Streaming replies, Markdown + code blocks
  • Works on desktop and phone widths

2Agents

  • Create as many agents as you like
  • Each has a name, instructions, model, color
  • Icon = a shape (blob, square, star, hex…) with 2 white eyes
  • Edit, duplicate or delete any agent

3Group chats

  • Put several agents in one chat
  • Parallel mode: all agents answer at once (fast)
  • Round-table mode: each sees the others’ replies
  • @mention to talk to one agent

4A computer per agent

  • Own sandboxed JavaScript runtime (Web Worker)
  • Own file system, saved on the device
  • Tools: run code, read / write / list / delete files
  • “Screen” previews HTML files the agent builds
  • Computers run side by side = faster work

5Models

  • OpenAI API, streaming + tool calling
  • Built-in list from GPT-4o up to “GPT-6 Astra”
  • “Load my models” pulls the live list for your key
  • Any custom model ID can be typed in

6Keys & privacy

  • API key entered in Settings, kept on the device only
  • Never baked into the app or the repository
  • Chats, agents and files stored locally
  • Export / import everything as JSON

7Five builds from one codebase

HTMLsingle file, any browser
APKAndroid, via Capacitor
EXEWindows installer, Electron
DMGmacOS, Electron
IPAiOS, Capacitor (unsigned)
This plan is built into the app: open the sidebar and choose “Build plan”.
