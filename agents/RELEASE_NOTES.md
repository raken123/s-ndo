ChatGPT Agents 1.0.0: a ChatGPT-style app where you chat with agents. Each agent has its own computer, and you can put several agents in one group chat.

| File | Platform | How to install |
|---|---|---|
| `chatgpt-agents.html` | Any browser | Open the file. |
| `ChatGPT-Agents-1.0.0.apk` | Android | Open it on the phone and allow "Install unknown apps". |
| `ChatGPT-Agents-Setup-1.0.0.exe` | Windows x64 | Run the installer. SmartScreen: More info → Run anyway (the installer is unsigned). |
| `ChatGPT-Agents-1.0.0-arm64.dmg` | macOS, Apple Silicon | Drag the app to Applications. On first launch, right-click → Open. |
| `ChatGPT-Agents-1.0.0-x64.dmg` | macOS, Intel | As above. |
| `ChatGPT-Agents-1.0.0.ipa` | iOS | Unsigned. Sideload it with AltStore, Sideloadly or your own Apple developer certificate. |

On first launch, open Settings and paste your OpenAI API key. The key is stored on your device only.
